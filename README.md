# Chiya Guran Dalahoo

وب‌سایت شخصی برای انتشار اشعار، نوشته‌ها و کتاب.

## ویژگی‌ها

- طراحی کاملاً راست‌چین (RTL) و مناسب زبان فارسی
- فونت وزیرمتن (Vazirmatn) برای خوانایی عالی
- واکنش‌گرا (موبایل، تبلت و دسکتاپ)
- منوی موبایل
- صفحات جداگانه برای:
  - صفحه اصلی
  - اشعار
  - نوشته‌ها
  - کتاب

## ساختار فایل‌ها

```
my-literature-site/
├── index.html          # صفحه اصلی
├── poems.html          # صفحه اشعار
├── writings.html       # صفحه نوشته‌ها
├── book.html           # صفحه کتاب
├── css/
│   └── style.css       # استایل‌ها
├── js/
│   └── main.js         # اسکریپت منوی موبایل
└── README.md
```

## چگونه استفاده کنید؟

### ۱. محتوای خود را جایگزین کنید

- **اشعار**: فایل `poems.html` را باز کنید و متن اشعار نمونه را با اشعار خودتان عوض کنید.
- **نوشته‌ها**: فایل `writings.html` را ویرایش کنید.
- **کتاب**: در `book.html` عنوان کتاب، توضیح، فهرست فصل‌ها و لینک‌ها را تغییر دهید.

### ۲. نام سایت و لوگو

نام سایت در حال حاضر **Chiya Guran Dalahoo** تنظیم شده است. اگر خواستید تغییر دهید، در همه فایل‌های HTML عبارت لوگو را ویرایش کنید.

### ۳. اجرا در کامپیوتر خود

فقط فایل `index.html` را با مرورگر باز کنید. نیازی به سرور نیست.

### ۴. انتشار آنلاین (رایگان)

چند روش ساده:

**الف) GitHub Pages (پیشنهادی)**
1. یک اکانت در GitHub بسازید
2. یک مخزن (Repository) جدید بسازید
3. فایل‌های این پوشه را آپلود کنید
4. در Settings → Pages، منبع را روی branch اصلی تنظیم کنید
5. سایت شما آنلاین می‌شود

**ب) Netlify**
1. به netlify.com بروید
2. پوشه را بکشید و رها کنید (Drag & Drop)
3. سایت فوراً آنلاین می‌شود

**ج) Cloudflare Pages یا Vercel** نیز گزینه‌های عالی هستند.

## شخصی‌سازی بیشتر

- رنگ‌ها را در فایل `css/style.css` در بخش `:root` تغییر دهید
- فونت را می‌توانید عوض کنید (لینک گوگل فونت در ابتدای CSS)
- برای افزودن صفحه جدید، از یکی از فایل‌های موجود کپی بگیرید
